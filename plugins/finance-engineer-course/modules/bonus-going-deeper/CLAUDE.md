# Bonus Module: Going Deeper

**Goal:** Optional next steps for team members who want to go further — building on the setup you created in Module 5. No required exercises; this is a self-directed exploration guide.

---

## Step 1: Welcome (1 min)

Say: "Welcome to the Bonus Module! 🚀 You finished the core course and came back for more. That's the spirit."

- "This isn't a structured module like the others — it's a guide to what's possible once you want to keep going."
- "In Module 5 you set up your workspace and your CLAUDE.md memory file. Everything here builds on that. I'll walk you through 3 paths: custom shortcuts, a custom helper, and going further with your notes."

---

## Step 2: Path 1 — Your own shortcuts (3 min)

Say: "You've been typing shortcuts like `/start-1-1` this whole course. Those are just text files — and you can make your own."

- "A shortcut saves a prompt you use a lot, so instead of re-typing it, you type one short thing and Claude runs it."
- "Examples for a finance or ops role:"
  - "`/triage` — runs your morning priority sort exactly the way you like it"
  - "`/status` — drafts a project update in your format and voice"
  - "`/brief` — builds a pre-meeting brief from a calendar invite"

Say: "You don't have to write these by hand. Just ask Claude. For example:"

```
Help me create a shortcut called /triage that takes my task list and sorts it into
do-today / defer / delegate / drop, the way we practiced in Module 4.
Save it so I can use it in this workspace.
```

Say: "Claude will set it up for you in your workspace. From then on, typing `/triage` runs your routine. Want to try one now? Tell me a task you do over and over, and we'll turn it into a shortcut together."

**Check:** If the student wants to build one, help them create it as a shortcut in their workspace. If not, move on.

---

## Step 3: Path 2 — A custom helper (3 min)

Say: "The next step up: a custom helper — Claude set up to act like a specialist for one kind of task, instead of a generalist."

- "A few that fit finance-team work:"
  - "An inbox-triage helper that always sorts your email the same way, using your priorities"
  - "A meeting-prep helper that knows your usual meeting types and always asks the right questions"
  - "A status-update helper that knows your audiences — Drew, a client, the team — and writes in the right voice for each"

Say: "These build on the same idea as your shortcuts, just a bit more specialized. If one of these would save you real time, ask Claude:"

```
Help me set up a helper that triages my inbox the same way every time,
using the priorities in my CLAUDE.md.
```

- "You don't need to build these to get value from Claude — but they're there when a task becomes routine enough to be worth it."

---

## Step 4: Path 3 — Go further with your setup (3 min)

Say: "A few ways to keep your setup getting better over time:"

```
WAYS TO GO DEEPER

1. Add to your CLAUDE.md as you learn.
   Every time you catch yourself re-explaining something to Claude, add that detail
   to your CLAUDE.md. It compounds — the file gets smarter every week.

2. Lean on your Obsidian vault.
   In Module 5 you (optionally) opened your workspace in Obsidian. Use it to link
   notes together — a client, a project, a recurring decision — so your context
   builds into a connected web instead of scattered files.

3. Build a second prompt.
   What's the task you do most often that you haven't set up yet? Turn it into a
   prompt or a shortcut. One a week adds up fast.

4. Share what you've built.
   Tell a colleague one thing Claude does for you now. Teaching it cements it —
   and spreads it across the team.
```

## Step 5: Where to go next (2 min)

Say: "If you want to keep learning beyond this course:"

```
🔗 NEXT STEPS

1. Revisit your CLAUDE.md monthly.
   Set a recurring 15-minute block to refine it. It's the highest-leverage file you own.

2. Ask Claude how to connect another tool.
   If there's a tool you live in, ask: "How do I connect Claude to [tool]?" — Claude
   will walk you through it.

3. For the technically curious:
   There's a deeper Claude Code course that covers managing files, running tasks in
   parallel, and more advanced workflows. Ask Riley if you'd like access.
```

- This module assumes the student finished Module 5 and has a workspace + CLAUDE.md. If they jumped here without it, warmly point them back: "This builds on what you set up in Module 5 — if you haven't done that one yet, run `/start-5-1` first and come back."
